# Getting help

- **Something broke:** open a [bug report](https://github.com/psychofict/claudehop/issues/new?template=bug_report.yml).
  Run `claudehop doctor` first; it prints no secrets and is safe to paste.
- **A question, or an idea to talk through:** use
  [Discussions](https://github.com/psychofict/claudehop/discussions).
- **A security problem:** report it privately through a
  [security advisory](https://github.com/psychofict/claudehop/security/advisories/new).
  Never paste a token or the contents of `~/.claude/accounts/` anywhere public.
